# Sweet As Box: full-box printed wrap

Every visible side of the kraft box gets a printed panel: the pattern lid, a red front, a "Packed by hand in
Wellington" back and both ends. The bottom stays plain kraft. Each panel is 3mm smaller than the box face, so a thin
kraft border frames it. That looks deliberate and means it doesn't need to be lined up perfectly.

## What you need
- **A4 full-sheet sticker paper** (one whole sticky sheet per page, not pre-cut labels) that suits your printer.
- A colour printer, or a print shop that will print onto your sticker sheets.
- A paper trimmer, or a craft knife and steel ruler.

## Printing
1. Print at **Actual size / 100%**. Don't choose "Fit to page".
2. Print one test set first and hold each panel against a box to check the size.

## Applying (about 3–4 minutes per box)
1. Pack the box and close the lid.
2. **Ends first:** peel and stick the left end ("Handle with love") and the right end ("This way up").
3. **Front and back:** stick the red front panel on the front wall, and the "Packed by hand" panel on the back.
4. **Lid last:** line the lid panel up with the kraft border showing evenly, and smooth it from the centre outwards.
5. **Seal:** put a round **"Open me!"** seal across the lid's front edge. It holds the box shut in the courier
   and tears when the lid is opened. Don't stick one big sticker across the lid's front edge, or the box can't open.
6. Write on the gift tag and stick it on, or tie it on.
