# Sweet As Box: packaging

## Main option: white box + printed lid
A plain white box with a full-colour lid sticker. The sticker has a white background, so it blends into the box and
the lid looks printed on. One A4 sheet per box also gives you a gift tag and 2 "Open me!" seals.

### Printing and applying (about 1 minute per box)
1. Print at **Actual size / 100%** on A4 full-sheet sticker paper. Print one test sheet first.
2. Cut along the solid line around the lid, then cut out the tag and the 2 seals.
3. Close the box. Peel the top edge of the backing and line the sticker up with the lid's back edge.
   It's 1mm smaller than the lid on every side.
4. Smooth it from the centre outwards.
5. Put an **"Open me!"** seal across the lid's front edge to hold it shut. It tears when the lid is opened.
6. Write on the gift tag and stick it or tie it on.
