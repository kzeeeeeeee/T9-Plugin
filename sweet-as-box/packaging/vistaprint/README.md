- **Front:** red panel, "A Kiwi Christmas in a box · Kiwi classics · posted NZ-wide".

Uploading: in the Vistaprint designer choose **Upload your design**, pick the PDF, and check that the preview
lines up with their cut lines. Order **outside print only**.
