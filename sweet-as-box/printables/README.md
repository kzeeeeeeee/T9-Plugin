# Sweet As Box: printables

Two cards go in every box: the **Kiwi Christmas Bingo** card and the **gift message card**.

## The files
| File | Use it for |
|---|---|
| `bingo-print-sheet-classic-A4.pdf` | **Print at home: Classic box bingo.** 2 cards per A4 (140×198mm). 4 pages: cards A+B, backs, cards C+A, backs |
| `bingo-print-sheet-mini-A4.pdf` | **Print at home: Mini box bingo.** 4 cards per A4 (100×141mm). Page 1 is cards A, B, C, A; page 2 is the backs |
| `message-card-print-sheet-A4.pdf` | **Print at home: gift message cards.** 8 per A4 (100×70mm). Page 1 is fronts, page 2 is backs |
| `bingo-card-classic-140x198.pdf` | One card per page (A, back, B, back, C, back). Use this for Canva or a print shop |
| `bingo-card-mini-100x141.pdf` | Same as above at the Mini size |
| `message-card-100x70.pdf` | One message card (front, back). Use this for Canva or a print shop |
| `preview-*.png` | Pictures of each card, for checking or for social media posts |

There are **three different bingo cards (A, B and C)** with the squares in a different order, so a whole family can
play together. Each one uses 24 of 30 Kiwi Christmas moments.

## Printing at home
1. Use **thick card**: 250–300gsm white card from Warehouse Stationery or OfficeMax.
2. In the print window, choose **Actual size / 100%**. Don't pick "Fit to page".
3. Choose **double-sided**. If the backs come out upside down, switch between
   "flip on long edge" and "flip on short edge" and print again.
4. Cut along the small black **crop marks** at the edges of the sheet. A paper trimmer is much faster than scissors.
   Each card has a white border around the red line, so a cut that's slightly off still looks fine.

**Tip:** print 5–10 sheets at a time as orders come in. Don't print hundreds up front.

## Before you print: check these placeholders
The back of the bingo card says:
- **@sweetasbox**: change it to your real Instagram handle.
- **Code MATE10 for 10% off**: create this discount code in Shopify (Discounts → Create discount → Amount off order),
  or change the text to the code you actually use.

## Editing in Canva
1. On the Canva homepage, select **Upload** and choose `bingo-card-classic-140x198.pdf` (or `message-card-100x70.pdf`).
2. Select the uploaded PDF to open it in the editor. You can now change the text, such as your handle,
   the discount code or bingo squares.
3. To file it, open **Uploads**, click the **⋯** on the file, choose **Move**, then pick
   **Sweet As Box → 02 Printables**.

The fonts are **Shrikhand** (headings) and **Fredoka** (body text). If Canva shows a different font after the import,
select the text and choose those fonts from the font list.
