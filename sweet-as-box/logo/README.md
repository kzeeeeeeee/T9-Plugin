# Sweet As Box: logo files

Retro Kiwi lolly logo. Every piece of text is converted to shapes (outlines), so the SVG files look exactly
the same in Canva, on a printer's website or in Shopify. You don't need the fonts installed to use them.

See `sweet-as-box-brand-sheet.png` for every version side by side.

## Which file to use
| File | Use it for |
|---|---|
| `sweet-as-box-logo-horizontal.svg` / `.png` | **Main logo.** Website header, invoices, email signature, Facebook cover |
| `sweet-as-box-logo-stacked.svg` / `.png` | Square spaces: box lid, flyers, market banner, gift cards |
| `sweet-as-box-icon.svg` / `.png` | Small spaces: website favicon, sticker sheets, social posts |
| `sweet-as-box-sticker-50mm.svg` / `.png` | **Print-ready 50mm round box-seal sticker** |
| `sweet-as-box-instagram-profile.png` | Instagram and Facebook profile picture (1080×1080) |
| `*-white.svg` / `.png` | The same logo for red or dark backgrounds |
| `*-onecolour.svg` / `.png` | One-colour black, for rubber stamps or black-only printing |

**SVG or PNG?** Use the **SVG** whenever possible, because it stays sharp at any size. Use the **PNG**
(transparent background, 2000px wide) if a website or app won't accept SVG.

## Putting it into Canva
1. Open Canva and click **Uploads** in the left panel, then **Upload files**.
2. Choose the SVG files from this folder. They show up in your Uploads, ready to drag into any design.
3. **Add the brand colours:** in any design, click a coloured element, then the colour square, then **+**, and
   paste each hex code below. If you have Canva Pro, add them under **Brand Kit** too, along with the logo files.
4. **For editable text in the same style,** search Canva's font list for **Shrikhand** (headlines) and
   **Fredoka** (body text). Both are free Google Fonts. If one isn't listed, use the logo files instead of
   retyping the name.
5. Don't stretch the logo. Resize it by dragging a **corner** handle so it keeps its shape.

## Fonts
- **Shrikhand** for headlines (retro 70s style). Free, licensed under the SIL Open Font License, so it's OK for commercial use.
- **Fredoka SemiBold** for prices, labels, cards and website text. Free, also under the SIL Open Font License.

## Printing the 50mm sticker
- Upload `sweet-as-box-sticker-50mm.svg`, or the PNG at 300 dpi, to Vistaprint NZ, StickerDot or your local printer.
- Choose a **50mm circle**. The file is 54mm across, which includes 2mm of **bleed** on every side (extra
  colour that gets trimmed off). If the printer asks for the file without bleed, tell them the trim size is 50mm.
- All the text sits at least 3mm inside the cut line, so nothing gets trimmed off.
- A gloss or satin paper sticker suits kraft boxes. Order 250 to start.
